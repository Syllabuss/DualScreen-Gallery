# Showcase assets

Captures supplied by Syllabuss from DS Gallery running on an AYN Thor. The JPEG files and animated GIF are preserved as supplied; none is bundled in the Android app.

| File | Shows |
| --- | --- |
| `photos-gif-dual-screen.jpg` | Image preview, GIF filmstrip, zoom navigator and floating music controls |
| `video-dual-screen.jpg` | Video player and episode browser |
| `favorites-dual-screen.jpg` | Mixed favorites and GIF preview |
| `online-tv-dual-screen.jpg` | A personally configured channel and saved-channel browser |
| `widgets-iisu.gif` | Widget sizes and playback effects on iiSU |
| `albums-dual-screen.jpg` | Album covers, mixed tile sizes and PIN-protected albums |
| `music-dual-screen.jpg` | Music playback with artwork colors and the song browser |
| `gaming-and-video-dual-screen.jpg` | A separate game above and DS Gallery video playback below |

The recording shows several configurations of the music widgets, not separate widget providers. iiSU, its wallpaper and desktop decorations are not part of DS Gallery. Captured media, artwork and channel logos belong to their respective creators and are not supplied by the app; the source-code GPL license does not relicense that material.

## Video and controls

The [YouTube showcase](https://www.youtube.com/shorts/gTU0hsluWSg) is linked from the root README. The README uses a normal link rather than an embedded player.

Y swaps the preview and browsing displays by default; X opens contextual options. Both are remappable. The game in the last capture is a separate application, not a DS Gallery feature.
